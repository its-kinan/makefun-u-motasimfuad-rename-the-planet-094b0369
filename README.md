One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters. The program writes the line to `/output/entry.txt`: Venus becomes "Drama Queen", because it spins backwards, its day outlasts its year, and it is hotter than Mercury despite standing farther from the Sun.

## Run it

```sh
node main.ts
```
